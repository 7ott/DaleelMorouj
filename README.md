## التحديث (3 خطوات)

### 1) قاعدة البيانات
Supabase ← **SQL Editor** ← **+ New query** ← الصق `crm-setup.sql` كله ← **Run**.
مش بيمسح أي داتا. بيضيف تسجيل تاريخ المراحل (عشان قمع البيع ومدة كل مرحلة يتحسبوا بدقة) وجدول لحفظ تقارير المستشار.

### 2) الرفع على GitHub
في الـ repo: **Add file ← Upload files**، واسحب الملفات دي كلها:
- `index.html`
- فولدر `api` بالكامل (اسحب الفولدر نفسه، مش الملف لوحده)

بعدين **Commit changes**. لازم يبقى عندك في الـ repo ملف `api/advisor.js`.

### 3) تفعيل المستشار الذكي
1. ادخل **console.anthropic.com** واعمل حساب، واشحن رصيد من **Billing**.
2. من **API Keys** اضغط **Create Key** وانسخ المفتاح (بيبدأ بـ `sk-ant-`).
3. في Vercel: المشروع ← **Settings** ← **Environment Variables** ← **Add**:
   - Key: `ANTHROPIC_API_KEY`
   - Value: المفتاح
4. **Deployments** ← آخر نسخة ← **⋯** ← **Redeploy**.

المفتاح بيتحفظ على سيرفر Vercel بس، ومحدش يقدر يشوفه من الصفحة. والمستشار مش بيرد غير على حد مسجّل دخول في النظام.
كل تحليل بيتخصم تمنه من رصيدك في Anthropic، وتقدر تحط حد أقصى للصرف الشهري من **Settings ← Limits**.

> التحليلات والتشخيص التلقائي شغالين من غير المفتاح. المفتاح مطلوب بس لتقرير الذكاء الاصطناعي والمحادثة.

## عضويات السيلز (4 حسابات)
بعد ما تشغّل `crm-setup.sql` وترفع الملفات:
1. Supabase ← **Authentication** ← **Users** ← **Add user** ← **Create new user**.
2. الإيميل: `sales1@murujdaleel.online` (وبعدين `sales2` و`sales3` و`sales4`، أو أي أسماء تحبها).
3. اكتب كلمة مرور لكل واحد، وعلّم على **Auto Confirm User**.
4. كل حساب جديد بيتسجل **سيلز** تلقائي. الموظف بيدخل باسم المستخدم بس (مثلاً `sales1`) وكلمة المرور.

من صفحة **الفريق والصلاحيات** في النظام تقدر:
- تغيّر صلاحية أي عضو (مدير / سيلز / موقوف).
- توقف حساب حد ساب الشغل، وتنقل عملاءه وصفقاته ومتابعاته لموظف تاني بضغطة.
- تشوف أداء كل عضو: عملاء، صفقات مفتوحة، مبيعات الشهر، متابعات متأخرة، وآخر نشاط.

| | المدير | السيلز |
|---|---|---|
| يشوف العملاء والصفقات | الكل | اللي باسمه بس |
| يضيف عميل أو صفقة أو متابعة | ✓ | ✓ (باسمه) |
| يغيّر مرحلة الصفقة وحالة العميل | ✓ | ✓ (بتاعه) |
| يضيف ملاحظات وسجل تواصل | ✓ | ✓ (على عملاؤه) |
| يحذف أي حاجة | ✓ | ✗ |
| يعدّل ملاحظة قديمة | ✓ | ✗ |
| الوحدات والمكاتب | يضيف ويعدّل | يشوف بس |
| تنزيل واستيراد Excel | ✓ | ✗ |
| التحليلات والمستشار الذكي | ✓ | ✗ |
| إدارة الفريق | ✓ | ✗ |

الحماية دي متطبقة **جوه قاعدة البيانات نفسها** (Row Level Security)، يعني حتى لو حد حاول يتجاوز الصفحة مش هيقدر يشوف أو يحذف حاجة مش من حقه.
ولما سيلز يضيف عميل برقم متسجل قبل كده، النظام بيمنعه ويقوله الرقم متسجل عند مين، عشان محدش ياخد عميل زميله.

## حسابي: الاسم وكلمة المرور
كل عضو (مدير أو سيلز) يفتح **حسابي**، من اسمه تحت في القائمة الجانبية، أو من **المزيد ← حسابي** على الموبايل:
- **الاسم اللي بيظهر**: مثلاً "سارة محمد". بيظهر في الترحيب والترتيب والسجلات وكل مكان في النظام. اسم الدخول (زي `sales1`) بيفضل زي ما هو لأنه مربوط بالعملاء والصفقات.
- **تغيير كلمة المرور**: بيطلب الحالية الأول، والجديدة لازم 8 حروف على الأقل.

لو حد نسي كلمة المرور: Supabase ← Authentication ← Users ← اضغط على المستخدم ← غيّرها من هناك.

## صاحب عرض الوحدة
في فورم الوحدة، خانة **صاحب العرض** بقت بتقبل أي حد:
- **أي حد متسجل في العملاء**: مالك أو وسيط أو تاجر أو عميل. اكتب جزء من الاسم أو الرقم واختار من القائمة.
- **أي مكتب** من دليل المكاتب.
- **اسم جديد مش متسجل**: اكتبه، هتظهرلك خانة رقم الهاتف وصفته (مالك / وسيط / شركة / أخرى). ولو علّمت على "سجّله كمان في العملاء"، بيتضاف لداتا العملاء.

رقم صاحب العرض المكتوب باليد بيظهر للمدير بس، والسيلز بيشوف "بيانات صاحب العرض مع الإدارة". وتقدر تدوّر على الوحدة باسم صاحب العرض أو رقمه.

## ترتيب الفريق ونظام النقاط
صفحة **ترتيب الفريق** ظاهرة لكل الأعضاء، حتى السيلز. بتعرض منصة لأول 3، والترتيب الكامل، وشارات الفترة (نجم الفترة، ملك التقفيل، الأكثر تواصلاً، ملك المعاينات، أسرع رد، الأكثر التزاماً)، وتقييم من 5 نجوم لكل عضو.

| النشاط | النقاط |
|---|---|
| بيع صفقة | +100 |
| تعاقد / حجز / تفاوض / معاينة (مرحلة) | +40 / +30 / +15 / +10 |
| تحديد الاحتياج / تم التواصل | +3 / +2 |
| معاينة مسجلة | +8 |
| مكالمة أو واتساب أو اجتماع (مرة لكل عميل في اليوم) | +1 |
| عميل جديد | +2 |
| أول رد خلال ساعة / خلال 24 ساعة | +5 / +2 |
| متابعة في ميعادها | +2 |
| متابعة متأخرة دلوقتي | −2 (بحد أقصى −30) |

كل مرحلة بتتحسب مرة واحدة بس لكل صفقة، فالرجوع والتقديم في المراحل مابيزودش نقط.
النقاط بتتحسب جوه قاعدة البيانات وبترجع إجماليات بس، فالسيلز بيشوف ترتيب زمايله من غير ما يشوف عملاءهم. حجم المبيعات بالجنيه بيظهر للمدير بس.

## الوضع النهاري والمظلم
زرار القمر/الشمس في الشريط اللي فوق (وفي صفحة الدخول) بيبدّل بين النهاري والمظلم، واختيارك بيتحفظ على الجهاز.

## التحليلات
بتختار الفترة (الشهر ده، 30 يوم، 90 يوم، السنة، من البداية) والموظف، وكل رقم بيتقارن بالفترة اللي قبلها.

- **8 مؤشرات أساسية**: عملاء جدد، صفقات مقفولة، حجم المبيعات، العمولات، نسبة الإغلاق، دورة البيع، سرعة أول رد، الالتزام بالمتابعات. ومعاهم اتجاه آخر 12 شهر.
- **مؤشر صحة المبيعات** من 100: سرعة الرد، المتابعات، الإغلاق، نظافة المسار، اكتمال البيانات.
- **قمع البيع**: كام صفقة وصلت كل مرحلة، ونسبة العبور، وأكبر مكان بتضيع فيه الصفقات.
- **مدة كل مرحلة** وعنق الزجاجة.
- **المبيعات المتوقعة**: احتمال البيع لكل مرحلة محسوب من صفقاتك الفعلية.
- **أسباب الخسارة** بالنسبة والقيمة.
- **أداء المصادر**: أنهي مصدر إعلان بيجيب بيع فعلاً.
- **أداء الفريق**: لكل موظف.
- **العرض والطلب** حسب المنطقة والنوع وشريحة السعر.
- **جودة الصفقات**: الخصم، العمولة الفعلية، عدد التواصلات في الصفقات الناجحة مقابل الخسرانة.
- **المخزون**: عمر الوحدات، الوحدات القديمة، سعر المتر بالمنطقة.
- **نشاط التواصل** حسب اليوم والوقت والنوع.
- **اكتمال البيانات**.

## المستشار الذكي
- **التشخيص التلقائي**: النظام بيطلع لوحده المشاكل من الأرقام، مرتبة من الأخطر، ولكل مشكلة الدليل والسبب وخطوات الحل.
- **تحليل الذكاء الاصطناعي**: تقرير كامل (الخلاصة، نقط القوة، المشاكل وأسبابها، جودة الصفقات، الفرص، الفريق، خطة الأسبوع والشهر، وأهداف بالأرقام). التقارير بتتحفظ وتقدر ترجعلها.
- **محادثة**: تسأله أي سؤال عن شغلك، وبيرد من أرقامك.
